# PM India · Конструктор баннеров

Опубликованная версия конструктора баннеров. `index.html` и картинки в `packs/` зашифрованы (AES-256-GCM, PBKDF2-SHA256) и открываются только по паролю.

Исходники и сборка: приватный репозиторий `darynal-dotcom/banner-builder` (`pages/build.js`). Этот репозиторий не редактируется вручную, он перезаписывается при каждой публикации.
